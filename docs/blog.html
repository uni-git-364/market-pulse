【今日の相場】10月12日（月）｜日本の金利だけが下がって円が全面安、東京休場の週明けは14日の米CPI待ち

9日のドル円はNY終値158.31円と反発し、ポンド円・ユーロ円もそろって上昇しました。日本の長期金利が0.070%低下する一方で米10年債利回りは5.24%へ上がり、金利差の拡大が円を全面的に押し下げた形です。12日の東京市場はスポーツの日で休場、焦点は14日の米CPIに移ります。

今日の3行まとめ

  • ドル円：9日のNY終値は158.31円（前営業日比+0.43円、+0.27%）と反発。ただし日本経済新聞（NQN）は158円35〜45銭、前日比50銭の円安と報じており、社によって数十銭の差があります（NYマーケットダイジェスト・9日／日本経済新聞）
  • ゴールド：COMEX金先物12月限の9日終値は4,216.30ドル（前日比+59.30ドル、+1.43%、みんかぶ）。Fiscoは4,221.42ドル（+64.42ドル、+1.55%）としており、中央銀行の買い観測が支えになったと報じられています
  • ビットコイン：11日午前時点で82,958ドル（前日比-2.2%、週間-2.15%）。円建ては10日時点で約1,307万円です。12日朝（執筆時点）の価格は確認できませんでした（BigGo ファイナンス／CRYPTO TIMES）

昨日（9日）の振り返り：イールドカーブが平らになり、円だけが置いていかれた

週末の取引を一本の線で説明すると、「日本の長期金利が下がり、米国の10年金利が上がった」という金利差の話に集約されます。

金利：日米で向きが逆になった

指標 9日の水準 前日からの動き
米10年債利回り（US10Y） 5.242%近辺で引け 上昇（日中は5.213〜5.276%）
日本10年債利回り（JP10Y） 3.010%（9日15時07分） -0.070%ポイント

（トレーダーズ・ウェブ「米国債市場概況・9日」／日本経済新聞「日本国債10年」）

米国の長期金利（10年国債の利回り。お金を10年貸したときの年利回り）が上がり、日本の長期金利が下がりました。日本の金利上昇幅が米国を上回れば金利差の縮小＝円高要因になりますが、9日はその逆で、金利差が広がる方向でした。これが円売りの土台です。

なお米債券市場については、Fiscoが「小反発、イールドカーブはやや平坦化」と報じています。10年は上がったが、より期間の長いゾーンは落ち着いたという読みで、後述する金の上昇はこちらの文脈に乗っています。10年の数字だけを見ると「金利上昇」、カーブ全体を見ると「平坦化」で、見出しが分かれているのはこのためです。

円要因かドル要因か：クロス円も同じだけ動いた

ドル円が動いたとき、原因が「円」にあるのか「ドル」にあるのかは、クロス円（ドルを経由しない円の組み合わせ）と並べると切り分けられます。

通貨ペア 9日終値 前営業日比 変化率
ポンド円 209.42円 +0.57円 +0.27%
ドル円 158.31円 +0.43円 +0.27%
ユーロ円 177.34円 +0.33円 +0.19%

（NYマーケットダイジェスト・9日／みんかぶ「9日の為替市場の四本値（ポンド円・豪ドル円・カナダ円）」。ポンド円の前営業日比は四本値の終値と前日終値208.85円からの計算値です）

ポンド円はドル円とまったく同じ+0.27%、ユーロ円も+0.19%でした。クロス円が同程度動いているので、これは円要因（円の全面安）と判定できます。

裏側からも確認できます。ユーロドルの9日終値は1.1200ドルで、前日の1.1212ドル相当からの下落幅は0.1%程度にとどまりました。ポンドドルは1.3229ドル相当で前日と変わりません。対ドルでの欧州通貨はほぼ動いていないのですから、ドル円の上昇はドル高ではなく円安で説明するのが素直です。

判定はすべて日足終値ベースです。日中の高値・安値（ヒゲ）は社によって数十銭ずれるため、方向の判断には使っていません。

株と原油：リスク回避は一服した

原油は上昇が止まりました。WTI11月限は引け前の確認値で1バレル91.23ドル（-0.26ドル、-0.28%）で、前日終値の91.49ドルから小幅安です。確定した終値は確認できませんでした。

この一服を受けて米国株は反発しました。速報系の時系列ではNYダウ51,654.95ドル（+423.31ドル、+0.83%）、ナスダック総合27,366.17（+0.64%）、S&P500は7,811.54（+0.59%）です。ただしこれは速報値で、確定終値は確認できていません（みんかぶ／stock-marketdata.com）。

日本株は9日の東京市場で日経平均が69,030.92円（前日比-11.19円）と小幅に3日続落しました。取引序盤は一時900円近く下げましたが、後場に買いが入って下げ幅をほぼ消しています（時事通信／株探）。

分かれ目：3市場で「自前の需給」が効いた

同じ1日で、金は上がり、ビットコインは上がりませんでした。マクロ環境は共通なので、違いはそれぞれの市場が抱える自前の買い手・売り手にあります。

  • 金：中央銀行の買い観測という自前の買い手がいて、長期ゾーンの金利の落ち着きが後押しになった → 1.4〜1.6%高
  • ビットコイン：米現物ETFから1週間で約6億8,000万ドルの資金流出という自前の売り手がいて、リスク回避の一服を打ち消した → 8万2,000ドル台で足踏み
  • 円：日米金利差という自前の要因で、通貨の中で一人負けした

ドル円

現在地

9日のNY終値は158.31円（前営業日比+0.43円、+0.27%）。200日移動平均線の直下で引けました。

材料

上向きの材料は上記の金利差拡大です。下向きの材料としては、16日に全国信用組合大会での植田日銀総裁のあいさつが予定されており、日銀の次の一手に関する発言が出れば円高方向に振れやすい地合いです。もっとも週の最大の材料は14日の米9月CPIで、それまでは方向が出にくいとの見方があります。

長期金利の高止まりの背景として、中東情勢に伴うインフレ懸念や高市政権の財政拡張路線への警戒感が挙げられています。財務省は10月6日発行分の10年国債の表面利率を年3.1%に設定しており、1996年8月の入札以来、30年2カ月ぶりの高水準です（時事通信）。金利の「高さ」自体は円の支えになり得る一方、9日は前日からの「向き」が下だったため円安に働いた、という点は分けて見る必要があります。

見通し

当面の分岐点は158.53円の200日線です。9日はこの線の22銭下で引けており、上抜けられるかどうかが決まっていない状態です。外為どっとコムは、雲の下限が下がってきていることから転換線（157.45円付近）が支えとして働くかが焦点だとしています。

ただし12日は米国の債券市場がコロンブス・デーで休場です。為替の方向を決めてきた米金利が動かないため、12日のうちに200日線の決着がつく可能性は低いとみるのが自然でしょう。実質的な判定は14日のCPI以降になります。

ゴールド

現在地

COMEX金先物12月限の9日終値は4,216.30ドル（+59.30ドル、+1.43%、みんかぶ）。Fiscoは4,221.42ドル（+64.42ドル、+1.55%）、海外メディアは4,220.3ドル（+1.52%）と報じており、社によって4,216〜4,221ドルの幅があります。上昇率が1.4〜1.5%程度という点では一致しています。週間では1.15%高と報じられています。

材料

Fiscoは上昇要因として「中銀の買い観測と米長期金利の低下」を挙げています。中央銀行による金購入は、外貨準備のリスク分散を目的とした継続的な需要とされ、外為どっとコムによれば9月下旬には中国人民銀行の金購入（20.2トン）も確認されています。※これらの数量は日本語メディア経由の引用です。

一方で週の前半は、FRBの10月利上げ観測が後退してもなお4,066ドルまで下落する弱さを見せていました（外為どっとコム、10月8日付）。「中銀の買いで下は堅いが、米金利の高さで上も重い」という綱引きが続いている、という整理になります。

見通し

9日の上昇でも、強弱の分岐点とされる4,245ドルには約29ドル届きませんでした。4,200ドル台を回復したが、4,245ドルの壁は手つかずという位置です。

外為どっとコムは、米CPIが下振れすれば利上げ観測の後退から金に追い風、上振れすれば実質金利（名目金利からインフレ率を引いたもの）の上昇とドル高で下押し圧力、と両方向を示しています。金利を生まない資産である金は実質金利に素直に反応しやすいため、14日のCPIが上下どちらに振れるかで景色が変わる、という見方です。

ビットコイン

現在地

11日午前時点で82,958ドル（前日比-2.2%）。週間では2.15%下落、年初来では5.20%のマイナスです。円建ては10日時点で約1,307万円（CRYPTO TIMES）。12日朝（執筆時点）の価格は確認できませんでした。

週中の値動きは、7日に84,000ドルを割り込み、8日に一時80,337ドルまで下げたあと、8万ドル台前半へ戻した形です。

材料

売り材料は需給です。米現物ビットコインETFは7日に約4億8,490万ドルの純流出となり、6月以来の大きさでした。1週間では約6億8,000万ドルの流出と報じられています。

bitbankのアナリストである長谷川友哉氏は、8万ドル近辺について、心理的な節目であるうえ日足一目均衡表の基準線とボリンジャーバンドの-2σが重なる水準であり、オプション市場でも建玉とポジティブガンマが集中しているため相応の下支えが期待できる、としています。そのうえで、8月以降の上昇に対する調整局面とみており、中期トレンドが反転したと判断するのは時期尚早との見方です。

ただし同氏は、現物ETFのフローが悪化している点には注意が必要で、流出が続けば8万ドル近辺での押し目買いも弱めかねないと指摘しています。「水準としての支えは厚いが、支えに来る買い手が細っているかもしれない」という留保つきの強気、と読むのが正確でしょう。

また、Glassnodeによれば81,000ドルの買い壁を割り込むと売りが連鎖する恐れがあると分析されています（日本語・海外メディア経由の引用）。上値については、85,000〜89,000ドルの帯に売り圧力が残るとの見方があります。

見通し

8万ドルの手前に、テクニカルな根拠が3つ（心理的節目・一目基準線・-2σ）重なっています。そのうえ81,000ドルには板の買い壁があるとされ、8万〜8万1,000ドルのゾーンは構造的に厚いという点では見方が揃っています。

割れているのは「そこで買うお金が来るか」という点です。ETFからの流出が続く限り、厚い支えでも抜けることはあり得ます。14日のCPIと15日のPPIで、インフレ指標が強ければ75,000ドルまでの調整も視野に入るとの報道があり、逆に下げ止まりとETFフローの改善が同時に確認できれば調整の終わりが近いという整理になります。同じ8万ドルを、「買い場」とみる根拠と「割れ得る」とみる根拠が両方そろっている状態です。

今日の心構え

東京休場・米債券休場という、1週間でもっとも材料の少ない日です。薄商いのなかで出た値動きは、方向を示すサインではなく単なる流動性不足の可能性があります。12日の値動きで判断を変えないことが、今日いちばんの心構えかもしれません。

以下は「ここを日足終値で超えたら見方を切り替える」という、シナリオ乗り換えラインの整理です。いずれも日足終値ベースで、日中のヒゲでは判定しません。

ドル円

  • 強気へ：158.53円（200日線）を日足終値で上抜け → 159.04円、159.61円を順に意識
  • 弱気へ：157.45円（転換線）を日足終値で割れ → 156.95円、155.97円を意識
  • 切り分け：ドル円が動いたらポンド円・ユーロ円の変化率を並べる。同程度なら円要因、ドル円だけならドル要因

ゴールド

  • 強気へ：4,245ドル（75日線・週足R1）を日足終値で上抜け → 4,330ドル方向
  • 弱気へ：4,050ドル（10月7日安値の下）を日足終値で割れ → 3,980ドル方向
  • 判断軸：米CPIが上振れなら実質金利の上昇とドル高で下押し、下振れなら追い風という整理

ビットコイン

  • 強気へ：85,000ドルを日足終値で上抜け → 89,000ドルまでの売り圧力帯の消化を確認
  • 弱気へ：80,000ドルを日足終値で割れて定着 → 75,000ドルが視野に入るとの指摘あり
  • 判断軸：価格だけでなく米現物ETFのフローを見る。流出が続くなら8万ドルの厚い支えも割れ得る

3市場に共通する判定日は14日です。それまでは、どのラインも「まだ試されていない」と考えておくのが安全でしょう。
