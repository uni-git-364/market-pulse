【今日の相場】10月9日（金）｜「イランを攻撃する／しない」が1日で2回ひっくり返り、原油と米金利が往復した

「イランを攻撃する」報道と「攻撃しない」発言が1日で入れ替わり、原油と米金利が往復しました。ドル円は157.88円へ下落、金は0.39%高で反発、ビットコインは8万1,000ドル台です。同じ材料で金とBTCが逆に動いた分かれ目は、効いた時間帯の違いでした。

今日の3行まとめ

  • ドル円：8日のNY終値は157.88円（前営業日NY終値158.08円から20銭安、-0.13%）。高値158.37円から安値157.52円まで、85銭の往復でした（ザイFX！「ニューヨーク外国為替市場概況・8日」／みんかぶ「8日の為替市場の四本値」）
  • ゴールド：COMEX金先物12月限の8日終値は4,157.00ドル（前日比+16.30ドル、+0.39%）と反発。中央銀行の買いと米長期金利の低下が支えになりました（みんかぶ「金は0.39%高＝NY金終値」／「反発、中銀の買いや米長期金利低下で＝NY金概況」）
  • ビットコイン：8日に8万3,000ドル、8万1,000ドルを相次いで割り込み、米東部時間18時09分時点で81,704ドル。約5億5,000万ドルの強制清算が発生しました。円建て参考値は約1,290万円です（CoinDesk／CryptoTicker）

昨日（8日）の振り返り：同じ道を、2回逆向きに通った1日

8日の相場は、「米国はイランを攻撃するのか、しないのか」という1点が1日で2回ひっくり返ったことで説明がつきます。

経路はずっと同じでした。原油 → 米長期金利 → ドルという一本道です。違ったのは向きだけで、東京からロンドンにかけては上りに、ニューヨークの後半は下りに通りました。

そしてこの「往復」が、金とビットコインに真逆の結果をもたらしました。ビットコインは上りの局面で売り材料を食らい、金は下りの局面で買い材料を得たのです。同じ日の同じ材料で正反対に動いたのは、材料の中身ではなく、材料が効いた時間帯が違ったからです。順に見ていきます。

第1段：上り――「攻撃準備完了を指示」の報道で原油が上がった

起点は、米国防総省が米中央軍に対し、イランでの大規模な戦闘作戦の再開に向けた準備を完了するよう指示した、との報道です。中間選挙前の攻撃再開の可能性が意識されました（みんかぶ「反発、米国がイラン攻撃再開を準備との報道で＝NY原油概況」）。

原油は東京時間の朝からじりじりと上昇し、時間外で90ドル台に乗せました（みんかぶ、8日14時30分・15時46分配信）。これが世界的な債券売り（＝金利上昇）を呼び、リスク資産には重石となりました。

第2段：上りの犠牲者はビットコインと日本株

この局面で売られたのが、暗号資産と株です。

ビットコインは8万3,000ドルを割り込み、さらに8万1,000ドルも下抜けました（CryptoTicker／CoinDesk）。日経平均は69,042.11円（前日比-993.60円、-1.42%）と続落し、終日売り優勢で安値引けとなりました（財経新聞／株探）。

ここが1日の分かれ目でした。この時点では、金利上昇が市場を支配していました。金利を生まない資産とリスク資産は、どちらも同じ理由で売られます。

日本時間21時30分、米国の新規失業保険申請件数（9月27日〜10月3日の週）が発表されました。

労働市場の底堅さに加え、原油高に連れた金利上昇が重なり、ドル買いが優勢になりました。原油はNY序盤に93.20ドルまで上値を伸ばし、ドル円は158.37円の高値を付けています（財経新聞「10月8日のNY為替概況」／みんかぶ）。

第6段：下りの受益者はゴールド

金利が下がった後半の局面で買われたのが、金です。

COMEX金先物12月限の8日終値は4,157.00ドル（+16.30ドル、+0.39%）。みんかぶは要因を中央銀行の買いと米長期金利の低下と伝えています（「反発、中銀の買いや米長期金利低下で＝NY金概況」、9日5時34分配信）。

第7段：円要因か、ドル要因か――答えはドル要因

ドル円が下げた理由が円高なのかドル安なのかを切り分けます。8日の変化率を並べます。

通貨ペア 8日NY終値 前日NY終値 変化率
ドル円 157.88円 158.08円 -0.13%
ユーロドル 1.1211ドル 1.1197ドル +0.13%
ユーロ円 約177.00円（逆算値） 176.98円 約0.0%

（ザイFX！「ニューヨーク外国為替市場概況・8日」／みんかぶ「8日の為替市場の四本値」）

ユーロ円の終値は、執筆時点で原文を確認できていません。表の約177.00円は、ドル円終値157.88円にユーロドル終値1.1211ドルを掛けた逆算値です。四本値として報じられた始値176.98円、高値177.44円、安値176.53円とは整合します。

結論は明快です。ドル円が-0.13%下がり、ユーロドルが+0.13%上がり、ユーロ円がほぼ動かなかった。つまりドルは円に対してもユーロに対しても同じだけ下がり、円とユーロの間では力関係が変わっていません。

これはドル要因です。昨日（7日）はユーロ単独の弱さが原因で、円もドルも動いていませんでした。8日はドルが単独で下がりました。2日続けてドル円の変動要因が違うので、ここは混ぜないほうが安全です。

ポンドも同じ方向でした。ポンドドルは1.3197ドルから1.3249ドルまで上昇しています。ただしポンド円の8日終値は執筆時点で確認できておらず、下落率の比較はできていません（7日終値は208.87円との記載があります）。

第8段：日米の長期金利差は縮小した。縮めたのは米国側

ドル要因という判定は、金利の側からも裏が取れます。

国 10年債利回り 前日比 時点
米国（US10Y） 5.229% -0.055 8日 NY16:34
日本（JP10Y） 3.080% -0.025 8日 15:09

（みんかぶ／日本経済新聞）

金利差は約2.15%ポイントで、前日の約2.18%ポイントから縮まりました。教科書どおり、金利差縮小は円高（ドル安）要因です。

ただし中身が大事です。縮小したのは、日本の金利が上がったからではなく、米国の金利が大きく下がったからです。日本も-0.025と下がっており、下げ幅が米国より小さかったにすぎません。つまり円が強くなったのではなく、ドルが弱くなった。第7段の為替の判定と、完全に一致します。

なお日本の数値は取引時間中（15時09分）のもので、確定した終値ではありません。日本証券業協会ベースの10年債利回りを3.070%とする資料もあり、取り方によって差があります。日中は11時台に3.075%まで低下し、超長期債に買いが目立ったと報じられています（日本経済新聞）。

ドル円：200日線に届かないまま、下に押し戻された

現在地

8日のNY終値は157.88円です。前営業日NY終値158.08円から20銭安（-0.13%）でした（ザイFX！）。終値を157.89円とする出典もあります（財経新聞）。差は1銭で、集計時刻の違いとみられます。

日中の足跡は往復でした。東京時間からロンドン時間は158円台前半でしっかりと推移し、17時03分時点では158.20円前後、16時01分には158.29円を付けています（みんかぶ）。NY時間に158.37円の高値まで上げた後、トランプ発言と金利低下を受けて157.52円まで反落しました。

高値から安値まで85銭。ここ数日の膠着からは、はっきり値幅が出た1日です。

材料

上を押した力（前半に効いた）

  • イラン攻撃再開報道による原油高 → インフレ懸念 → 米金利上昇
  • 新規失業保険申請件数19.7万件（予想20.0万件を下回る）＝労働市場の堅調さ
  • 国内実需筋の円売り・ドル買い観測

上を抑えた力（後半に効いた）

  • トランプ大統領の「中間選挙前の攻撃計画はない」との言明 → 原油反落 → 米金利低下
  • 30年債入札の底堅い需要 → 長期金利の押し下げ
  • 200日移動平均線という節目の存在
  • 158円台での日米通貨当局による円安けん制への警戒

結果として、2日続けて200日線に届いていません。7日は東京高値158.51円で1銭届かず、8日は高値158.37円で手前から押し戻されました。

見通し

当面の構図は、2日前から変わっていません。200日移動平均線を日足終値で上抜けられるかどうかです。

ただし8日で状況は少し変わりました。2日続けて手前で止められたことです。7日は1銭差、8日は15〜37銭差（算出元による）で届いていません。節目が重く見られるのは、そこに特別な力があるからではなく、多くの参加者が同じ線を見て注文を置いているからです。2回止まったという事実は、その見方を補強します。

もっとも、8日の下落はドル側の事情でした。イラン情勢という、カレンダーに載らない材料がドルを動かしました。これは上にも下にも同じ速さで効くということです。トランプ大統領の発言が1日で原油を93.20ドルから90.21ドルまで振り回したことは、逆向きにも同じ幅で起こりうると見るのが素直でしょう。

見方は割れています。上を見る側は日米金利差の大きさ（約2.15%ポイント）と労働市場の堅調さを根拠にします。上がらないと見る側は、200日線で2度止められたこと、158円台での介入警戒、そして10月の利上げ見送り観測を挙げます。どちらの材料も現に存在しており、現時点でどちらが優勢とは言えません。

下については、157.52円の8日安値と、その下の157.40円台が目先の支えになるかが分かれ目です。

ゴールド：金利が下がった後半に、買い戻された

現在地

COMEX金先物12月限の8日終値は4,157.00ドルです。前日比+16.30ドル（+0.39%）でした（みんかぶ「金は0.39%高＝NY金終値」、9日2時57分配信）。

ここで昨日の記事の数値を1つ確定させておきます。昨日は7日終値を「約4,140ドル（-1.11%からの計算値）」としていました。今回確認できた報道では、7日終値は4,140.70ドル（-46.40ドル、-1.11%）です。計算値はほぼ正確でした。

直近3営業日の先物の推移を並べます。

スポット（現物）は別の系列です。OANDAは7日のスポット終値を4,111.33ドルとしています。先物とスポットには30〜45ドル程度の差があるため、他媒体の「4,100ドル台」という表現と本記事の先物の数字は、同じ相場を別の指標で見たものです。

材料

8日の反発要因は2つと伝えられています。

1つは中央銀行の買いです。みんかぶは押し目が買われた背景として中央銀行の買いを挙げています。ただし具体的にどの中銀が、いくら買ったかは、執筆時点で日本語メディア経由でも確認できていません。数値を示せない以上、ここは「そう報じられている」までにとどめます。

2つめは米長期金利の低下です。これが本記事の因果の線と直結します。米10年債利回りが-0.055、30年債が-0.066と下がったことで、金利を生まない金の機会費用（持っているだけで失う利息）が下がりました。

逆に、上げを一服させたのは原油高です。原油が上がるとインフレ懸念から金利が上がりやすく、金には重石になります。金は1日のなかで、原油高に押さえられながら金利低下に支えられるという綱引きの中にいました。

注目したいのは、前日との対比です。7日は「原油高 → 金利上昇 → 金安」でした。8日は「金利低下 → 金高」です。金の方向は、金自身の事情ではなく米金利が決めているという構図が、2日続けて確認できたことになります。

見通し

外為どっとコムの週間見通し（10月8日時点、対象は10月8日〜15日）は、予想レンジを3,980〜4,330ドルとし、FRBのタカ派姿勢（金融引き締めに前向きな姿勢）が金の重石になっているとしています。

材料

下げは3つの層が重なりました。

第1に、マクロ要因です。イラン攻撃再開報道による原油高と、それに伴う世界的な債券売り・金利上昇です。CoinDeskはこの日のライブ記事を「債券売りと原油高の強まりでリスク資産が圧迫される」という見出しで伝えています。ビットコインが下げたのは前半の局面で、金が反発した後半の局面ではありません。ここが8日の金とビットコインの分岐点でした。

第2に、強制清算です。約5億5,000万ドル相当のポジションが清算され、その初動はレバレッジを掛けた買い（ロング）ポジションの投げだったと複数の媒体が伝えています。清算額は集計期間と集計元で数字が変わり、別の報道は24時間で約1億1,900万ドル（約188億円）としています。価格下落が清算を呼び、清算が次の下落を呼ぶ自己増殖的な構図です。

第3に、ETFの資金流出です。CoinDeskは「ビットコインETFから1日で5億ドル近くが流出した」と報じ、7日の米国現物ビットコインETFの純流出を約4億8,490万ドルとしています。CryptoTimesは約4億8,700万ドルとしています。数カ月で最大規模の流出との表現です。9月には約26.5億ドルの純流入があったため、流れの反転が目立ちます。

なおbitbankは10月8日付の相場分析で、7日にBTCが節目の8万5,000ドルを終値ベースで割り込み、先週末の上抜けがダマシに終わったことでテクニカル面のセンチメントが悪化したと指摘しています（7日終値は前日比2.76%安の約1,318万円）。同社は日足RSIの弱気ダイバージェンス（価格が高値を更新する一方で指標が追随しない状態）にも以前から言及していました。

見通し

節目を3つ連続で下に抜けたという事実が、まず重いです。10月7日に85,000ドル、8日に83,000ドルと81,000ドルを割りました。bitbankが10月8日付のレポートで問いかけているのは「8万ドルまで調整が深まるか」です。

一方で、8日の下げ幅は24時間ベースで一時約4%まで広がったあと、取引終盤には約2%まで縮小しました（CoinDesk）。売り一色で終わってはいないということです。

ここで押さえておきたいのは、8日後半のマクロ環境はビットコインに有利に転じていた点です。米金利は低下し、原油は反落し、金は反発しました。それでもビットコインが8万1,000ドル台にとどまっているのは、ETFの資金流出と清算後の需給が、マクロの改善を打ち消しているという読み方ができます。

逆に言えば、マクロが追い風のうちに戻せないなら、問題はマクロではなく需給の側にあるということです。ここは今日の値動きで検証できる部分です。

ただしこの解釈は執筆時点での推測です。8日後半のビットコインの値動きを金利低下と結び付けて直接論じた記事は、執筆時点で確認できていません。

今日の心構え

8日は、同じ材料が時間帯によって正反対の結果を生むことを見せた1日でした。イラン情勢という1つの材料が、前半はビットコインと日本株を売り、後半は金を買い戻し、ドルを売りました。

材料を見たときに「これは金にプラスか、マイナスか」と考えると、8日のような日は読めません。どの経路を通るか（今回は原油 → 米金利 → ドル）と、それが自分の見ている市場の時間帯に届くかを分けて考えるほうが実用的です。

もう1つ。ドル円の下落はドル要因でした。7日はユーロ単独の弱さ、8日はドル単独の弱さです。2日続けて、クロス円の動きからドル円を推し量ると間違えます。ユーロ円が動かず、ユーロドルが上がり、ドル円が下がった――この3つを並べて初めて「ドルが単独で下がった」と判定できます。
