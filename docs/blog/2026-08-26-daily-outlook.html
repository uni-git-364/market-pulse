2026-08-26今日の相場

【今日の相場】8月26日（水）｜今日、すべてが決まる。PCE・GDP・エヌビディアが1日に並ぶ

今日の3行まとめ

  • ドル円：159円台前半で狭いレンジ。介入警戒と米財政懸念に上下から挟まれ、身動きが取れない
  • ゴールド：4,690ドル台。前日比0.07%安とほぼ横ばい、高値圏で待機
  • ビットコイン：8万ドル手前で反落。7万9,000ドル前後で攻防中

今日の21時30分に米7月PCEデフレーターとGDP改定値、そして米国市場終了後にエヌビディア決算。物価と景気と半導体の需要が、1日に並びます。

今日という日の特殊性

今週ずっと「待ちの相場」と書いてきましたが、その待ち時間が今日で終わります。

「指標から金利へ、金利から株価へ」という道筋が最も凝縮されるのが8月26日、と指摘されている通りです。

21:30：米7月PCEデフレーター、4-6月期GDP改定値、耐久財受注、個人所得 米国市場終了後（日本時間27日朝）：エヌビディア決算

そして東京市場がこの結果を受け取るのは、明日27日の朝です。

なぜPCEが特別なのか

PCEデフレーターはFRBが物価動向を判断するうえで最も重視する指標です。CPIより広い範囲をカバーし、消費者の購買行動の変化も反映されます。

6月のコアPCEは3.3%と、目標の2%から離れたままでした。ここから鈍化しているかどうかが焦点です。

インフレ鈍化が確認された場合：FRBの追加利上げ観測が後退し、米長期金利の低下を通じてドル売りが強まる可能性。

インフレの粘着性が確認された場合：金融引き締めの長期化が意識され、米長期金利の上昇とともにドル円が再び160円台を試す材料に。

同日のGDP改定値で米景気の底堅さが維持されているかも注目で、PCEとGDPがともに強い結果となれば、米金利上昇を通じてドル高が進む可能性があります。

見ておきたい伏線：ウォルマートの数字

ここは意外と重要です。20日に発表されたウォルマートの米国既存店売上高は2.6%増で、市場予想の3.8%増を下回りました。ガソリン高が家計を圧迫しているとの見方が広がっています。

先週の小売売上高が予想外のマイナスだったことと合わせると、米国の消費は確かに弱っている可能性があります。今日のGDP改定値と個人消費支出の実額は、この仮説を検証する材料になります。

エヌビディア決算の焦点

数字だけ押さえておきましょう。会社側の売上高見通しは910億ドル、市場予想は872億ドルです。

ただし焦点は単に好決算かどうかではなく、現在の高い株価水準を正当化できる成長率や業績見通しを示せるかにあります。

エヌビディア株は決算を前に7営業日連続の続落ペースとなっており、市場の警戒感は高まっています。昨日のNY市場では半導体株に買い戻しが入り、ナスダックもプラス圏に戻す場面がありましたが、これは決算前のポジション調整の色が濃いでしょう。

ドル円：159円台前半、上下から挟まれた膠着

現在地：159円台前半

昨日のNY市場は狭いレンジでの推移が継続し、ウォーシュ議長の講演を控えた様子見ムードでした。

上値を抑える「2つの重し」

みんかぶのNY為替概況の見出しが的確です。介入警戒に加え、米財政を巡る懸念が上値を抑える。

これは今の相場の本質を突いています。通常、ドル円の上値を抑えるのは介入警戒だけですが、今は米財政への懸念という第2の重しが加わっています。

昨日ベッセント財務長官が示唆した「TGA（財務省一般勘定）の約1兆ドルを活用したバイバック拡大」は、金利を下げる一方で「そこまでしないと長期金利が抑えられないのか」という疑問を市場に残しました。

米金利が高くてもドルが買われない——この現象が、今週ずっと続いています。

今週の予想レンジは157.00〜160.50円とされています。

見方が分かれている

外為どっとコムの整理が示唆的です。米長期金利の水準を重く見るか、それとも金利が戻してもドルが買われなかった事実を重く見るかで、同じ材料から逆の結論が出るため、市場では見方が分かれている、と。

  • A：米長期金利の高さを重視 → 158円台は押し目、160円方向へ
  • B：金利が戻してもドルが買われなかった変化を重視 → 158.36円割れから157円方向へ
  • C：どちらとも決めない → 158.36円割れか160.20円超えを確認してから、抜けた方向に合わせる

今日のような日は、Cが最も合理的です。PCE一つで両方のシナリオが生き死にするからです。

ゴールド（XAU/USD）：高値圏で待機

現在地：4,690ドル台（前日比0.07%安）

昨日のNY金はほぼ横ばいで引けました。前日に4,700ドル台に乗せた後、高値圏を維持しています。

今日のシナリオ

金にとってのPCEは、単純です。

インフレ鈍化 → 金利低下 → 金は追い風 インフレ粘着 → 金利上昇 → 金は逆風

ただし今回は少し複雑な要素があります。もしPCEが上振れて「インフレ再燃」と受け取られれば、金利上昇（マイナス）とインフレヘッジ需要（プラス）が同時に働きます。

金は「インフレ」ではなく「実質金利」で動く——名目金利の上昇幅がインフレ期待の上昇幅を上回れば、金は下がります。この見極めがポイントです。

水準観

  • 上値：4,700ドルを固められるか。超えれば5月高値圏が視野
  • 4,580〜4,600ドル：5月に何度も弾かれた重要抵抗帯。突破済み
  • 下値：4,500ドル（旧200日線）を割ればブレイク失敗

なお昨日は中東情勢の進展期待で原油が下落しており、WTIは85ドル台前半へ。地政学プレミアムの剥落は、金にとってはやや逆風です。

ビットコイン（BTC/USD）：8万ドルの壁に跳ね返される

現在地：7万9,000ドル前後

昨日、BTCは8万882ドルまで上昇し、5月15日以来約113日ぶりに8万ドルを突破しました。しかしその後、7万8,700〜7万9,000ドルの範囲に反落しています。

今年3度目の敗退か

改めて整理すると、8万ドルは今年に入って3度目のトライです。

時期 結果
5月4日 8万ドル突破後に反落
5月15日 8万1,600ドル台まで上昇後、8万ドル割れ
8月25日 8万882ドルまで上昇後、反落

この価格帯は過去のデータでも強い抵抗線として機能しており、単なる通過点ではなく激しい攻防が繰り広げられる領域です。

清算データが示すもの

CoinGlassの集計では、価格上昇前後の4時間で約1億7,900万ドルが清算されました。

  • ショート：約1億200万ドル
  • ロング：約7,900万ドル

ロングも7,900万ドル清算されている点が重要です。上に飛びついた人も、下で耐えていた人も、両方が振り落とされている。レバレッジが集中し、ボラティリティが極めて高い状態です。

今日の注意点

BTCにとって今日は二重のリスクがあります。

  1. PCE → 金利を通じた影響
  2. エヌビディア決算 → AI・ハイテク株を通じた影響

BTCは近年、ナスダックとの連動性が高い局面が多く、エヌビディアが崩れればリスク資産全体に波及します。BTCも例外ではありません。

水準観

  • 上値：80,000〜81,600ドル（今年3度跳ね返された抵抗帯）
  • 下値：69,609ドル（200日線）→ 67,100ドル（短期保有者の平均取得価格）

今日の心構え

結論から言えば、今日の日中は動かず、21:30を待つのが最も合理的です。

理由は3つ。

① 位置が最悪 ドル円159円台前半は、上の抵抗（160.10〜160.20円）まで約1円、下の支持（158.36円）まで約0.8円。どちらに動いても値幅が限られる中途半端な位置です。

② 1日で方向が決まる PCE、GDP、エヌビディアが同じ日に並びます。その前にポジションを作るのは、3回連続のコイントスに賭けるようなものです。

③ 明日の朝が本番 東京市場がこの結果を受け取るのは27日の朝です。日本時間の夜中に方向が決まり、朝には織り込まれている。寝ている間に勝負がつく日でもあります。

シナリオの乗り換えラインを確認しておきましょう。

  • ドル円：160.10〜160.20円を日足終値で上抜け → 75日線160.47円が視野／158.36円（200日線）を明確に割る → 157円方向へ
  • ゴールド：4,700ドル固め → 上昇継続／4,500ドル割れ → ブレイク失敗
  • BTC：80,000〜81,600ドルを日足終値で上抜け → 3度目の正直／69,609ドル割れ → 上昇シナリオ崩壊

ある投資戦略レポートは、今週の方針をこう表現していました。新しく買うのは26日を通過してから。それまでは持ち高を増やさずに構えます。

シンプルですが、これ以上の答えはないと思います。今日という日は、当てにいく日ではなく、確認する日です。
