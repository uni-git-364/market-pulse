【今日の相場】8月28日（金）｜PCE上振れで一服、今夜はウォーシュ初講演とBTC64億ドルの満期

米7月PCEの上振れを受けて長期金利が上昇し、ドル高・金安・ビットコイン軟調という素直な反応が出た一日でした。今夜23時にはウォーシュFRB議長の就任後初講演、ビットコインは64億ドル規模のオプション満期を控えます。

今日の3行まとめ

  • ドル円：159.30円台で推移。本日の予想レンジは158.70〜159.80円、ウォーシュ講演待ちで方向感に乏しい展開
  • ゴールド：NY市場は4,592.02ドルで引け、前日比46.08ドル安（-0.99%）。4,600ドル台を維持できず反落
  • ビットコイン：7万8,500〜7万9,000ドル前後。8万ドル定着に失敗したまま、今夜17時に64億ドル規模のオプション満期を迎える

昨日の振り返り：デベースメント・トレードが一旦巻き戻された

今週前半、金・ビットコイン・ドル円が同時に上がるという珍しい現象が続いていました。その背景にあったのが「デベースメント・トレード」（財政悪化による通貨価値の希薄化を懸念し、ドルではなく金やビットコインなど、通貨ではないものを買う動き）です。

昨日（27日）はこの流れが一旦巻き戻されました。

きっかけは前日発表の7月米PCE（個人消費支出）物価指数です。前年比3.7%上昇と、市場予想（3.6%）を上回りました。これを受けてFRBの9月利上げ観測が高まり、米10年債利回りは4.6%台後半まで上昇。金利上昇が一時的な話に終わらず、27日のNY市場まで高止まりが続いたことが、昨日1日の値動きを決定づけました。

金利が上がる→利回りのつかない金は売られ、レバレッジの効いたビットコインも売られ、ドルは相対的に買われる。この極めてオーソドックスな連動が、昨日の3市場を貫く共通の駆動要因でした。ドル円は一時159.44円前後まで上値を試す場面があり、ゴールドはNY引けで4,592.02ドルまで下落。ビットコインも8万ドルの節目を回復できないまま7万8,000ドル台後半へ押し戻されています。

なお、26日発表の4-6月期米GDP改定値は前期比年率+1.5%と、速報値・市場予想からの変化なし。同日発表のエヌビディア決算は売上高962億ドル（市場予想922億ドル）と好内容で、発表直後は株価が下落する場面もありましたが、その後は買いが優勢となり終値比+4.5%程度まで戻す乱高下となりました。AIバブルへの警戒は多少和らいだ形ですが、ビットコインはこの株式市場のリスクオンには連動せず下落したままで、今の相場を動かしているのは株式センチメントよりも金利・ドルの動きだという点が改めて確認できます。

ドル円（USD/JPY）

現在地：159.30円台

本日の予想レンジ：158.70〜159.80円

上値のメドは今月18日につけた月間高値159.78円前後、下値のメドは今週安値の158.71円前後とされています。

材料

27日のNY市場では、前日のPCE上振れを引き継いだドル買いが続き、一時159.44円前後まで上昇する場面がありました。もっとも、市場では今夜28日のウォーシュFRB議長の講演を見極めたいとのムードが強く、深夜にかけては積極的な上値追いにはならず、159.3円台へ伸び悩んで東京朝方を迎えています。

FRBの9月利上げ織り込みは約4割、日銀の9月利上げ織り込みは約9割とされており、日米双方の金融政策の先行きが不透明な中、方向感の出にくい綱引き相場が続いています。

ゴールド（XAU/USD）

現在地：4,592.02ドル（NY引け、前日比-46.08ドル、-0.99%）

前日26日には一時4,690ドル台まで買われましたが、金利上昇を受けて上げ幅を縮小し、27日は4,600ドル割れで取引を終えています。

材料

米長期金利の上昇が金にとっての逆風となり、3営業日ぶりの反落となりました。ただし週間ベースでは8月14日の4,376ドルから大きく水準を切り上げており、上昇トレンドそのものが崩れたわけではないとの見方が優勢です。

外為どっとコムの週間見通しでは、インフレが上振れても、その金利上昇が「財政リスクの表れ」として読まれる限りは金の重しになるとは限らないと指摘されており、金利上昇をどちらの文脈で市場が受け止めるかが当面の分かれ目とされています。

ビットコイン（BTC/USD）

現在地：7万8,500〜7万9,000ドル前後

26日に一時8万1,000ドル台まで上値を伸ばしましたが、その後は利益確定売りとPCE後の金利上昇を受けて反落し、8万ドルの節目を回復できないまま27日を終えています。

材料

8万ドルは年初来これで複数回跳ね返されている水準で、今回も定着には至りませんでした。米長期金利の先行きが再びタカ派方向に傾いたことに加え、株式市場のリスクオン（エヌビディア決算後の反発）にも連動しなかった点は、目下の値動きが金利主導であることを示しています。

今夜17時（日本時間）には、デリバティブ取引所Deribitで約64億ドル相当（約81,700枚）のビットコインオプションが満期を迎えます。建玉はコール（買う権利）44,858BTC、プット（売る権利）33,681BTCで、プットコール比率は0.75。コールが優勢な構成であるため、価格が上昇した場合はヘッジ解消の買いが値動きを増幅させる可能性がある一方、下落した場合はその逆の力学が働く可能性があります。

今日の心構え

3市場を貫く共通の駆動要因は、引き続き米長期金利（10年債利回り）とドルの方向感です。昨日はこの金利が上振れたことで「ドル高・金安・ビットコイン安」がそろい、金利低下局面で見られた「円高・金高・ビットコイン高」の逆パターンとなりました。この3つを同時に保有しても、値動きの方向が重なりやすく分散効果は限定的になりやすい点は、今回もそのまま当てはまります。

判定はいずれも日中の一時的な値動き（ヒゲ）ではなく、日足終値ベースで考えるのが基本です。シナリオの乗り換えラインを確認しておきます。

  • ドル円：日足終値で159.80円を上抜け → 上値追いを試す展開／158.70円を下回る → 下押し警戒、200日線158.34円が視野
  • ゴールド：日足終値で4,600ドル台を回復・維持 → ディベースメント・トレード再開の目安／フィボナッチ23.6%押し目4,531ドルを明確に下回る → 調整局面入りを警戒
  • ビットコイン：日足終値で80,000ドルを回復・定着 → 4度目の正直で上値追い／今夜のオプション満期通過後に下押しが強まり69,609ドル（200日線）方向への調整に警戒

ウォーシュ議長の初講演は、本人が過度なフォワードガイダンスに否定的とされているため、明確な政策シグナルが出ない可能性もあります。その場合でも、発言のトーン自体（タカ派的か、ハト派的か）が金利・ドルを通じて3市場に波及する構図は変わりません。材料が出尽くすまでは無理に方向を当てにいかず、確認を優先する日と位置付けたいところです。
