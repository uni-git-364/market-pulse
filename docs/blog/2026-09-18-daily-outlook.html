【今日の相場】9月18日（金）｜日銀1.25%へ、焦点は会見の「次の一手」

原油安と米金利低下でドル高が一服し、ドル円は17日終値155.97円へ小幅反落しました。金は4,399.70ドルへ続伸、ビットコインは7万6,000ドル台で下げ渋っています。きょうは日銀が1.25%への利上げを決める見通しで、焦点は植田総裁の会見です。

今日の3行まとめ

  • ドル円：17日は始値156.26円 → 高値156.32円 → 安値155.34円 → 終値155.97円（みんかぶ四本値）。16日終値156.36円からは小幅反落で、FOMC後のドル買いが一服しました
  • ゴールド：NY金先物12月限の17日終値は4,399.70ドル（前日比+12.20ドル・+0.28%）で続伸。原油安と米国債利回りの低下が理由です（みんかぶ）。スポット価格（XAU/USD）の17日終値は執筆時点で確認できず
  • ビットコイン：17日は7万6,200〜7万6,600ドル台での集計値が並びます。円建ての直近確定値は16日終値1,189万778円（ビットバンク、BTC/円）。18日朝の水準は執筆時点で確認できず

昨日の振り返り：ハンドルを握ったのはFOMCから「原油」に替わった

16日と17日は、同じ3市場がほぼ正反対の反応をしました。ただし、これは相場が気まぐれだったからではありません。値動きの起点が入れ替わったからです。

16日の線：FOMCのドット → 米金利上昇 → ドル高・株安

16日は、FOMC（米連邦公開市場委員会）が3年ぶりに0.25%の利上げを決め、同時に公表したドット・チャート（参加者ひとりひとりの政策金利見通しを点で示した図）で2026年末の中央値が4.125%へ引き上げられたことが起点でした。当局者18人中16人が年内あと1回の利上げを見込む形です（トレーダーズ・ウェブ）。

結果、米10年債利回りは5.02%（+0.02%）へ上昇し、NYダウは631.21ドル安の51,461.90ドルと3日続落、下げ幅は一時900ドルを超えました（株探、OANDA証券）。ドル円は154.86円まで下押ししたあと156.42円まで急伸し、156.36円で引けています。

17日の線：原油安 → 米金利低下 → ドル安・金高

ところが17日は、起点が金融政策から原油に替わりました。

NY原油（WTI）先物は16日に102.43ドル（-3.40ドル）と下げ、17日のNY朝方にはさらに99ドル台まで軟化しました。原油が下がるとインフレ期待が後退するため、債券が買われて利回りが下がります。実際、米10年債利回りはNY時間に4.94%台まで低下しました（みんかぶ）。Investing.comによれば、この低下は9営業日ぶりの下落にあたります。

ここから3市場に枝分かれします。

  • ドル円：米金利が下がった → 日米の金利差が縮む方向 → ドル売り。NY朝方に155.34円まで下落
  • ゴールド：金は利息を生まない資産なので、金利が下がると保有の機会費用が減る → 買い。加えて原油安でドルの上昇も一服。4,399.70ドルへ続伸
  • ビットコイン：金利上昇という逆風が緩んだ → 下げ渋り。ビットバンクは17日のレポートを「タカ派FOMCも下げ渋る 材料出尽くしで買い戻し」とまとめています

つまり16日は「金利が上がって、金利に弱いものが一斉に売られた日」、17日は「その金利が原油につれて下がって、同じものが買い戻された日」でした。逆再生に近い動きです。

ただしドル円については、その後NY午後に156円台へ買い戻され、終値は155.97円まで戻しています。日銀会合を前にした持ち高調整が入ったと見られ、一方向には終わりませんでした。

円要因か、ドル要因か → 17日は「ドル要因」が主、「円要因」は従

ドル円が動いたとき、円が買われたのか、ドルが売られたのかは、クロス円（ドル以外の通貨と円のペア）と比べると切り分けられます。17日の四本値（みんかぶ）で、始値から終値までの変化率を並べます。

読み方はこうなります。

ユーロ円も-0.08%とわずかに下げているので、円は全面的にやや強かったと言えます。これは円要因です。しかしドル円の下げ幅はその2倍以上あり、さらにユーロドルが上昇（＝ドルが売られた）しています。円が強かった分より、ドルが弱かった分のほうが大きいという構図です。

したがって17日はドル要因が主、円要因が従と判定します。前日16日が純粋なドル要因（クロス円がほとんど動かなかった）だったのに対し、17日は円側の材料も少し混ざり始めた、という違いがあります。

なお、ポンド円の四本値は執筆時点で確認できませんでした。参考として、NY時間のポンドドルは1.3390近辺で推移しており（みんかぶ）、ドル円終値155.97円で試算するとポンド円は208.84円程度になりますが、これは終値ではなく日中の参考値です。

ただし日本側の引値が未確認なので、この判定は暫定です。日本の長期金利は日銀の追加利上げ観測と財政懸念の両方で上昇しており（日本経済新聞）、きょうの会合結果を受けてさらに動く可能性があります。

材料

きょうの主役は日銀です。日銀は17〜18日の会合で政策金利を1.0%程度から1.25%程度へ引き上げる見通しと報じられています（日本経済新聞、ブルームバーグ）。実現すれば1995年以来、約31年ぶりの水準です。6月会合以来3か月ぶりの利上げで、2024年3月のマイナス金利解除以降では最短の間隔になります。

ここで注意したいのは、利上げそのものはほぼ織り込み済みという点です。市場が見ているのはその先のペースです。

そして、今週の特殊な事情がここに効いてきます。米国が先に利上げしてしまったため、日本が0.25%上げても日米の金利差は縮まりません。だから「日銀が利上げしても円安は止まらないのではないか」という見方が出ています（外為どっとコム、ハロンズFX）。ストラテジストからも、日銀が利上げ継続への確信を市場に与えられなければ円安がさらに進む可能性があるとの指摘が出ていました（みんかぶ）。

一方で、反対の見方もあります。市場の関心は利上げの到達点（ターミナルレート）と次の一手のタイミングに集まっており（ブルームバーグ）、日本経済新聞は会見の「3つの注目ワード」に注目すると伝えています。会見で想定以上に前向きなペースが示されれば、円が買われる余地はあります。どちらに転ぶかは会見を聞かないと分かりません。

なお、短期金融市場では来年6月までに米国であと3回の利上げが織り込まれているとの指摘もあります（みんかぶ）。この織り込みが正しいかどうかも、中期的なドル円の水準を左右します。

見通し

5日移動平均線（154.52円）が現在地より下、21日移動平均線（157.07円）が上にあります。移動平均線は一定期間の平均値をつないだ線で、5日線は目先の勢い、21日線はひと月程度の重心を表します。目先は上向きだが、ひと月の重心はまだ上にあるという、方向が決まりきっていない配置です。外為どっとコムは17日時点のテクニカル一覧を「底打ちから上昇の流れが続く」とまとめています。

したがって上値では157.07円の21日線が最初の壁、下値では155.34円の17日安値が最初の支えになります。この間はどちらに動いても、日銀会合の結果次第で簡単に覆る範囲とお考えください。

判断はすべて日足終値ベースで行います。きょうは会見の一言で日中に大きなヒゲ（一時的に付けただけの高値・安値）が出やすい日なので、日中の瞬間値で方向を決めつけないことが特に重要です。

材料

17日の金の続伸理由は、みんかぶのNY金概況が「原油安や米国債の利回り低下で」と明確に示しています。金は利息を生まない資産なので、金利が下がるほど「債券より金を持ったほうが不利ではない」という力学が働きます。

ここで興味深いのは、外為どっとコムが17日の週間見通しで挙げていた反発の条件が、そのまま実現した点です。同社は反発条件として「原油高の一服と米長期金利の低下」「100日移動平均線（4,321ドル）の回復」「中国人民銀行の金購入や中国金ETFへの資金流入」を挙げ、下落リスクとして「FOMCの利上げと年内の追加利上げ観測」「米10年債利回り5%台とドル高」を挙げていました。

17日はこのうち原油高の一服と米長期金利の低下という2つが同時に起きたわけです。金が上がったのは偶然ではなく、事前に整理されていた条件を満たしたからと読めます。

もっとも、下落リスクのほうも消えていません。FOMCが年内あと1回の利上げを示唆した事実は変わらず、米10年債利回りは4.94%台と、5%からわずかに下がっただけです。高金利という構造的な逆風は残ったままです。長期の上昇トレンドが続くと見る向きと、転換したと見る向きの両方があります。

  1. 米金利上昇（弱まった）：米10年債利回りが5.02%から4.94%台へ低下。ビットバンクは以前から、短期金利の上昇とイールドカーブのフラット化（短期金利と長期金利の差が縮まること）を通じたBTCへの下押し圧力を警戒していましたが、17日はこの圧力が一時的に緩みました
  2. 原油高（弱まった）：WTIが99ドル台へ軟化し、インフレ経由の金利上昇圧力も後退
  3. クラリティ法案の頓挫（残る）：15日に米上院で暗号資産の規制区分を定める法案が採決に必要な60票に届かなかった件は、制度面の不透明さとして残っています

一方で、制度面には前向きな動きも報じられています。米ビットコイン準備金法案が下院委員会を通過したと伝えられており（JinaCoin）、規制の話が一方向ではなくなってきました。

ビットバンクの17日レポートの見出しは「BTCはタカ派FOMCも下げ渋る 材料出尽くしで買い戻し」です。悪材料が出尽くしたという整理が、いまのところ優勢ということになります。

きょう固有の論点として、日銀の利上げがあります。円の金利が上がると、円を借りてリスク資産を買う取引（円キャリー取引）の採算が悪化するため、理屈のうえでは暗号資産にも下押し圧力になります。コインチョイスもこの観点から日銀会合を取り上げています。ただし0.25%の利上げがどの程度この経路で効くかは見方が分かれており、過大評価は避けたいところです。

今日の心構え

今週は「FRBが先に動き、日銀が後から動く」という順番の週でした。この順番が重要です。米国が0.25%上げたあとに日本が0.25%上げても、日米の金利差は縮まりません。だから、きょう利上げが発表されても、それだけでは円高の理由にならないという点を最初に押さえておくと、値動きの解釈がぶれにくくなります。

見るべきは金利差の「いま」ではなく「この先の変化の方向」です。会見で示されるペース感が、そこを決めます。
