【今日の相場】10月22日（木）｜原油安が米金利を下げ、株とBTCが走った日

  • ゴールド：COMEX金12月限の21日終値は4,150.00ドルで前日比+7.40ドル（+0.18%）の反発。原油高の一服が買い材料となった一方、米国債利回りの上昇で上げ幅は縮小しました（みんかぶ「反発、原油高一服も上げ一服＝NY金概況」10月22日5時32分）
  • ビットコイン：22日早朝は8万4,600ドル前後で、一時8万4,700ドル超。24時間で約2%上昇し、前日までの8万2,000ドル台から水準を切り上げました（NADA NEWS「ビットコイン8.4万ドル台に上昇、米ハイテク株高と金利低下が追い風」）
