【今日の相場】10月29日（木）｜タカ派据え置きでもドルは伸びず、原油反発が金を削る

  • ビットコイン：29日早朝時点で81,661ドル（24時間で約1.2%高）。FOMC通過で売りポジションの清算が進み、8万ドル割れからようやく頭を出した水準です。
