【今日の相場】10月9日（金）｜「イランを攻撃する／しない」が1日で2回ひっくり返り、原油と米金利が往復した

「イランを攻撃する」報道と「攻撃しない」発言が1日で入れ替わり、原油と米金利が往復しました。ドル円は157.88円へ下落、金は0.39%高で反発、ビットコインは8万1,000ドル台です。同じ材料で金とBTCが逆に動いた分かれ目は、効いた時間帯の違いでした。

  • ドル円：8日のNY終値は157.88円（前営業日NY終値158.08円から20銭安、-0.13%）。高値158.37円から安値157.52円まで、85銭の往復でした（ザイFX！「ニューヨーク外国為替市場概況・8日」／みんかぶ「8日の為替市場の四本値」）
  • ゴールド：COMEX金先物12月限の8日終値は4,157.00ドル（前日比+16.30ドル、+0.39%）と反発。中央銀行の買いと米長期金利の低下が支えになりました（みんかぶ「金は0.39%高＝NY金終値」／「反発、中銀の買いや米長期金利低下で＝NY金概況」）
  • ビットコイン：8日に8万3,000ドル、8万1,000ドルを相次いで割り込み、米東部時間18時09分時点で81,704ドル。約5億5,000万ドルの強制清算が発生しました。円建て参考値は約1,290万円です（CoinDesk／CryptoTicker）
