【今日の相場】10月29日（木）｜タカ派据え置きでもドルは伸びず、原油反発が金を削る

FOMCは政策金利を3.75〜4.00%で据え置き、2人の委員が利上げを主張して反対しました。それでもドルは伸びず、ドル円は158.35円まで上げた後157.84円へ失速。原油の102.78ドルへの反発が、金を4,051.60ドルまで押し下げています。

  • ドル円：28日のNY終値は157.84円（前営業日比0.11円安、0.07%安）で4日ぶりの小反落。FOMC直後に158.35円まで上げたものの維持できず、200日移動平均線（158.54円）の手前で跳ね返されました。
  • ゴールド：COMEX金12月限は4,051.60ドル（23.00ドル安、0.56%安）と反落。原油がWTIで102.78ドル（2.88ドル高、2.9%高）へ3営業日ぶりに反発し、インフレ懸念が金利上昇経路から金を圧迫しました。
  • ビットコイン：29日早朝時点で81,661ドル（24時間で約1.2%高）。FOMC通過で売りポジションの清算が進み、8万ドル割れからようやく頭を出した水準です。
