【今日の相場】9月17日（木）｜FRBが3年ぶり利上げ、ドル円156円台へ

FRB（米連邦準備制度理事会）は17日未明、3年ぶりとなる0.25%の利上げを全会一致で決めました。ドル円は発表後に156円台を回復し、金は4,300ドル前後、ビットコインは7万6,000ドル近辺で重い動きです。きょうからは日銀の金融政策決定会合が始まります。

  • ドル円：FOMC（米連邦公開市場委員会）の利上げ発表を受けて154.86円から155.60円へ急伸し、その後156.13円近辺まで上昇しました（フィスコ、みんかぶ、17日4時33分時点）。16日のNY終値は執筆時点（17日朝）で確認できず、15日のNY終値は155.14円です
  • ゴールド：16日は4,293ドルまで下落し、4,300ドルの節目を割り込む場面がありました。利上げ決定後の終値は執筆時点で確認できず。直近で確認できるNY金先物12月限の終値は14日の4,330.51ドル（フィスコ集計）です
  • ビットコイン：16日は7万6,000ドル前後、円建てでは約1,179万円で推移しました（ビットバンク、BTC/円）。15日は始値1,206万円 → 終値1,176万円。FOMC後も米金利上昇が重しになっています（CoinPost）
