【今日の相場】9月24日（木）｜米金利5%台、3連休明けの東京が3日分を一度に織り込む日

  • ゴールド：NY金先物12月限の23日終値は4,318.40ドル（前日比-58.00ドル、-1.33%）で3日続落。米PMIを受けた利上げ観測と金利上昇が重しになりました（みんかぶ）
