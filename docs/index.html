【今日の相場】11月17日（火）｜エヌビディア決算前の「持ち高たたみ」が3市場を同時に削った日

  • ビットコイン：15日に一時62,006ドルまで急落し約3カ月ぶりの安値、16日時点では約64,900ドルで推移（CoinPostによる）。円建てでは一時1,000万円を割り込みました。
