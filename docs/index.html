【今日の相場】10月8日（木）｜原油がすべての起点。金とBTCは沈み、ドル円だけ200日線の手前で止まった

ホルムズ海峡でのタンカー攻撃が原油を押し上げ、インフレ懸念から米金利とドルが上昇しました。金は1.11%安、ビットコインは8万3,000ドル台へ下落。一方でドル円は158.08円と、200日移動平均線の1銭手前で止まっています。

  • ドル円：7日のNY終値は158.08円（前営業日NY終値158.10円から2銭安、-0.01%）。東京時間に158.51円まで上げたものの、200日移動平均線の158.52円を抜けられませんでした（ザイFX！「ニューヨーク外国為替市場概況・7日」／外為どっとコム）
  • ゴールド：COMEX金先物12月限の7日終値は前日比-1.11%。原油高に伴う米金利上昇とドル高が重しになりました。絶対額は執筆時点で原文を確認できておらず、6日終値4,187.10ドルから逆算すると約4,140ドルです（みんかぶ「金は1.11%安＝NY金終値」）
  • ビットコイン：7日に84,000ドルを割り込み、米東部時間18時05分時点で83,232ドル。円建て参考値は約1,315万円です。5億4,600万ドルのロスカットが発生し、その88%が買いポジションでした（CoinDesk／The Crypto Times）
