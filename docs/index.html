【今日の相場】11月27日（金）｜NYが休んだ「16銭の凪」、主役は8時半の東京CPIへ

26日のNY市場は感謝祭で休場、ドル円はNY時間の値幅がわずか16銭という凪でした。ドル円は159.25円で引け、金は3,596ドル前後、ビットコインは6万ドル台を回復しています。本日は8時半の東京都区部CPIが最初の材料です。

  • ドル円：26日のNY終値は159.25円。前営業日のNY終値159.17円から8銭程度のドル高で、小幅続伸でした。米国が感謝祭で休場だったためNY時間の値幅は約16銭にとどまり、高値は日本時間1時ごろの159.34円です（MyForex／DZHによる）。
  • ゴールド：米市場が休場のため確定した当日終値はありません。時間外のスポット（現物）は3,596ドル前後で、25日に付けた15カ月ぶり安値3,454ドルからは反発した水準です（みんかぶ、各社アナリストレポートによる）。
  • ビットコイン：25日の安値57,209ドル付近から反発し、26日は60,000〜61,000ドルのレンジで推移、日中高値は61,509ドルでした（Bitstampのデータ、Bitcoin.com Newsによる）。感謝祭の薄商いのなか、ショート（売り持ち）の買い戻しが上昇の主因とされています。
