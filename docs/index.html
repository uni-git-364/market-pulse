【今日の相場】9月21日（月）｜利上げしたのに円全面安、止めたのはレートチェック

日銀が1.25%へ利上げした18日、円はドルだけでなく主要通貨すべてに対して売られ、ドル円は158.05円まで上昇しました。流れを止めたのは市場ではなく、日銀によるレートチェック報道です。きょうから日本は3連休に入り、薄商いのなかでの介入警戒が焦点になります。

  • ドル円：18日は始値155.97円 → 高値158.05円 → 安値155.87円 → 終値156.88円（みんかぶ四本値）。日銀の利上げ後にむしろ円安が進み、レートチェック報道で押し戻されました
  • ゴールド：NY金先物12月限の18日終値は4,416.67ドル（前日比+16.97ドル・+0.39%）で3日続伸。スポット（XAU/USD）は4,341ドル前後まで戻し、100日移動平均線4,321ドルを上回りました（OANDA証券）
  • ビットコイン：18日に8万ドルを回復し、19日には8万1,400ドルまで上昇。20日は8万443〜8万1,260ドルで推移しています。米現物ETFへ18日に4億3,300万ドルの純流入がありました
