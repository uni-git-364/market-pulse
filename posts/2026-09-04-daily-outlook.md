## 昨日の振り返り：日米の金融政策観測が同時に逆を向いた一日

3日の市場を動かしたのは、**日米の金融政策観測が同時に、しかも逆方向に振れた**という一点です。これがドル円・金・ビットコインの3市場すべてを貫く共通の因果になっています。

まず円サイドです。日銀関係筋の話として「今月の金融政策決定会合で政策金利を0.25ポイント引き上げ、1.25%とする公算」と報じられました。9月2日に高田審議委員が連続利上げや大幅利上げの可能性に言及した流れを引き継ぐ内容で、ドル円は2日にすでに160円台前半から158.72円前後まで急落していました。3日はこの観測がさらに強まり、加えて「GPIF（年金積立金管理運用独立行政法人）が国内資産への投資を増やすのではないか」との思惑も重なって円買いが加速しています。

一方のドルサイドでは、FRBのウォラー理事が「インフレ圧力の鈍化が確認されれば、政策金利の据え置きを支持する」と発言しました。この日は米新規失業保険申請件数の増加、7月貿易赤字の拡大、4-6月期単位労働コスト確定値の下方修正と弱い数字が並んでおり、米早期利上げ観測が後退してドル売りが優勢となりました。前日2日に発表された8月ADP雇用統計が3.8万人増と市場予想を下回っていたことも、この見方を後押ししています。

ただし一方的な話ではありません。米8月ISM非製造業景況指数は55.4（予想54.1、7月54.1）と予想外に改善し2月以来の高水準となったため、債券の上値は徐々に重くなりました。仕入れ価格項目が上昇した点はインフレ再燃の芽として残ります。

### 「円要因」か「ドル要因」か

ドル円が大きく動いたときは、円が買われたのか、ドルが売られたのかを切り分ける必要があります。3日のNY終値ベースで比較すると次のとおりです。

| 通貨ペア | 3日NY終値 | 前営業日NY終値 | 変化率 |
|---|---|---|---|
| ドル円 | 155.81円 | 158.71円 | -1.83% |
| ユーロ円 | 181.14円 | 183.93円 | -1.52% |
| ポンドドル | 1.3548ドル | 1.3490ドル | +0.43% |

クロス円（ドル以外の通貨と円の組み合わせ）であるユーロ円も-1.52%とドル円に近い下落率を記録しており、ポンド円も一時209.97円まで下押ししました。クロス円がそろって同程度下げている以上、**今回の主因は「円要因」＝円買い**と判定できます。そのうえでポンドドルが+0.43%と上昇していることから、**ドル売りが上乗せされた**構図です。円買いとドル売りが同じ方向に重なったため、ドル円の下落率が最も大きくなりました。

### 長期金利は「差」で説明できない

日米の長期金利は、米10年債利回りが前営業日比0.05%低い4.68%、日本の新発10年国債利回りが0.045%低い2.965%と、**ほぼ同じ幅でそろって低下**しました。金利差はほとんど縮まっておらず、長期金利の差だけでは今回の円高は説明できません。

つまり今回動いたのは10年金利ではなく、**政策金利そのものの織り込み**です。日銀は9月17〜18日の会合で1.25%への利上げが強く意識される一方、FRBは9月15〜16日のFOMCで据え置き観測が浮上した。この「政策金利の距離が縮まる」という将来の予想の変化が、長期金利の動きを飛び越えて為替に効いた形です。なお以下の判定はすべて日足終値ベースであり、日中のヒゲ（一時的な高値・安値）では判断していません。

## ドル円（USD/JPY）

### 現在地：155.81円（3日NY終値）

3日のNY市場でドル円は大幅に続落し、155.81円で引けました。日本時間4日2時前には一時155.30円と、8月3日以来1カ月ぶりの安値を更新しています。外為どっとコムの参考レートは4日2時12分時点で155.49円でした。

### 材料

円買い材料は日銀の9月利上げ観測（0.25ポイント引き上げて1.25%とする公算との報道）とGPIFの国内資産シフト思惑、ドル売り材料はウォラーFRB理事の据え置き容認発言と弱い米指標群です。両者が同時に効いたことで下落幅が拡大しました。

上値を抑える構図が続く一方、米8月ISM非製造業景況指数が予想を上回った点は米金利の下げ止まり要因として残っています。方向を決めるのは本日21時30分の米8月雇用統計で、これが日米双方の金融政策観測を一度に検証するイベントになります。

### テクニカル水準

外為どっとコムの4日2時12分時点のデータでは、RSI（相対力指数・14日、買われすぎ／売られすぎを0〜100%で測る指標）は28.63%と売られすぎ目安の30%を下回りました。ボリンジャーバンド（価格の振れ幅を統計的に示す帯）の下限も割り込んでいます。

| 水準 | 価格 |
|---|---|
| ボリンジャーバンド2σ上限 | 161.01円 |
| 90日移動平均線 | 160.06円 |
| 21日移動平均線 | 159.02円 |
| 5日移動平均線 | 158.84円 |
| 200日移動平均線 | 158.46円 |
| ボリンジャーバンド2σ下限 | 157.09円 |
| **現在地（3日NY終値）** | **155.81円** |
| 3日安値（1カ月ぶり安値） | 155.30円 |

### 見通し

見方は割れています。慎重派は「200日移動平均線もボリンジャーバンド下限も割り込んだ以上、下降トレンドへの転換を疑うべきで、日銀会合まで戻り売りが出やすい」とみます。一方で強気派は「RSIが売られすぎ圏に入っており、日銀の利上げは相当程度織り込まれた。米雇用統計が強ければ短期的な買い戻しが入りやすい」と指摘します。

判断の分かれ目は、日足終値でボリンジャーバンド下限157.09円を回復できるかどうかです。回復できなければ下押し圧力が残り、逆に回復すれば200日移動平均線158.46円までの戻りが視野に入ります。

## ゴールド（XAU/USD）

### 現在地：4,400ドル近辺（3日）

3日の金相場は4,400ドル近辺で推移しました。ドル安と米長期金利の低下が同時に進んだことが追い風です。金は利息を生まない資産のため金利低下は保有コストの低下を意味し、またドル建てで取引されるためドル安は他通貨を持つ投資家にとって割安になります。今回はこの2つが同時に効きました。

なお3日のNY終値の確定値は執筆時点で確認できておらず、日中の推移水準として記載しています。

### 材料

前週から今週初めにかけて、金は米長期金利の上昇を受けて200日移動平均線や100日移動平均線を相次いで割り込む下落局面にありました。3日はその金利が反転低下したことで、下げの主因が一時的に取り除かれた形です。

外為どっとコムは9月3日付の週間見通し（9月3日〜9月10日が対象で、この期間限りの参考値）で、ベースシナリオを4,250〜4,550ドルのレンジ内での推移とし、方向を決める判断軸は4日の米雇用統計を受けた米金利と利上げ観測の動きだとしています。14日RSIは50.0まで低下し、過熱感はほぼ解消しました。

### テクニカル水準

| 水準 | 価格 |
|---|---|
| 週間予想レンジ上限（外為どっとコム、9月3日時点） | 4,550ドル |
| 200日移動平均線（9月1日時点の概算） | 4,510ドル前後 |
| **現在地（3日）** | **4,400ドル近辺** |
| 25日移動平均線 | 4,392ドル前後 |
| 100日移動平均線 | 4,356ドル前後 |
| 75日移動平均線 | 4,259ドル前後 |
| 週間予想レンジ下限（外為どっとコム、9月3日時点） | 4,250ドル |

### 見通し

現在地は25日移動平均線のすぐ上、100日移動平均線の上という位置取りで、上には割り込んだばかりの200日移動平均線が戻り売りの目安として控えます。米雇用統計が弱く米金利が一段と低下すれば200日移動平均線の回復を試す展開が想定される一方、雇用が強ければ利上げ観測が再燃し、100日移動平均線から週間レンジ下限に向けた下押しが意識されます。

金利低下は追い風ですが、ISM非製造業の仕入れ価格上昇が示すインフレの粘りは、金にとって支援材料（インフレヘッジ需要）にも逆風材料（利上げ観測の再燃）にもなり得ます。どちらに転ぶかは金利の反応次第で、現時点で一方に決め打ちできる状況ではありません。

## ビットコイン（BTC/USD）

### 現在地：77,151ドル（3日8時時点、前日比-0.18%）

ビットコインは77,000ドル台で小動きにとどまりました。8月に一時80,000ドルまで急伸したものの、その水準の定着には至っていません。円建てでは2日終値が1,242万円（前日比-1.1%）でした。

### 材料

株高・金利低下というリスク選好が優勢な環境にもかかわらず、ビットコインが大きく上昇しなかったのは、本日の米雇用統計待ちで積極的な売買が手控えられたためです。bitbankの分析によれば、4日の米雇用統計に加えて2万9,359BTC規模のオプション満期が重なるため、発表を前に様子見が続きやすい地合いとされています。

同社は、米労働市場の底堅さが確認されれば利上げ観測の高まりから短期金利が一段と上昇し、BTC相場の重しとなる可能性を指摘しています。逆に労働市場の鈍化が確認されれば、利上げ観測の後退から買いが強まりやすい構図です。ドル円や金と同じく、本日の雇用統計が起点になります。

### テクニカル水準

| 水準 | 価格 |
|---|---|
| 8月高値ゾーン | 80,000ドル前後 |
| 心理的節目 | 79,000ドル |
| **現在地（3日8時時点）** | **77,151ドル** |
| 高値レンジ下限（bitbank） | 75,500ドル前後 |

円建てでは、bitbankによれば14EMA（指数平滑移動平均、直近の価格を重く見る移動平均）が1,214万円、53EMAが1,116万円に位置し、53EMAが上昇していることから長期トレンドは強気を示唆するとされています。高値レンジの下限は7万5,000ドル台中盤（およそ1,210万円）です。

### 見通し

短期は方向感を欠いた膠着ですが、長期の移動平均が上向きを維持している点は下値の支えとして意識されます。ただしイールドカーブ（年限ごとの金利をつないだ曲線）のフラット化には引き続き警戒が必要とされており、短期金利の上昇が続く局面では上値が重くなりやすい状況です。

## 今日の心構え

本日は米雇用統計という単一のイベントが3市場すべてを動かす日です。発表前のポジションの傾きと、発表後の初動の巻き戻しには注意が必要です。以下はいずれも日足終値ベースでの判断ラインです。

**ドル円のシナリオ乗り換えライン：157.09円（ボリンジャーバンド2σ下限）**

日足終値でここを回復すれば「下げ一服・戻り局面」に切り替え、200日移動平均線158.46円を次の目標として見ます。回復できずに155.30円を日足終値で下回れば「下降トレンド継続」と判断し、154円台を視野に入れます。

**ゴールドのシナリオ乗り換えライン：4,392ドル（25日移動平均線）**

日足終値でこれを上回って推移する間は「金利低下を追い風にした戻り」のシナリオを維持します。下回った場合は100日移動平均線4,356ドル、さらに週間レンジ下限4,250ドルへの下押しシナリオへ乗り換えます。

**ビットコインのシナリオ乗り換えライン：79,000ドル**

日足終値でこれを回復すれば80,000ドル再挑戦のシナリオに切り替えます。逆に高値レンジ下限の75,500ドル前後を日足終値で割り込めば、8月からの上昇局面がいったん終了したと判断し、下値模索のシナリオへ乗り換えます。

3市場に共通するのは「米金利がどちらに動くか」という一点です。雇用が強ければ利上げ観測の再燃で金利上昇、ドル買い・金売り・BTC重しという組み合わせが、弱ければその逆が基本形になります。ただしドル円については日銀会合という円サイドの材料が別途控えているため、米金利だけでは説明しきれない動きが出る可能性があります。
